## 機能概要

入力CSVの各セルが、システムDBのどのフィールドに対応するかを定義・管理する画面。標準マッピングと特別領域マッピングの2種類の変換定義を扱う。

> **背景**: 「各種ファイル連携」でアップロードされるCSVの各セルは、システムDBの特定フィールドに保存される。どのセルがどのフィールドに対応するかを事前に定義しておく必要がある。DBには「特別領域」が10枠存在し、特別領域を使う場合はタイトル用セルと値用セルの2つを指定する。また「雑コード」と呼ばれる汎用コードが存在し、その実態はCSVの他カラムを組み合わせた文字列テンプレートで定義する。
>
> **変換定義の種類**:
>
> - **標準マッピング**: 入力CSVの該当セルを、DBの指定フィールドの値として保存する
> - **特別領域マッピング**: 入力CSVの該当セルをDBの特別領域n（1〜10）のタイトルとして使用し、別の該当セルをその値として保存する
>
> **レイアウト方針**: 機能1・2は同一セクション内に配置する（定義ファイルの管理をまとめて表示）。機能3は独立したセクションとして縦に配置する。

## 機能詳細

### 機能1: ~~手入力用マスターアップロード~~ → アイテムマスターアップロード [2026/05/08 修正要件により変更済み]

- [ ] 独立したセクションとして表示する
- [ ] CSVファイルを選択できるファイル添付UIを表示する
- [ ] ファイル選択後、「アップロード」ボタンをクリックするとファイルを送信できる
- [ ] アップロード対象ファイルは CSV 形式のみ許可する
- [ ] 「定義内容を表示」ボタンを配置し、クリックで機能3のオフキャンバスパネルを開く [2026/05/08 追加]

### 機能2: 変換定義CSVアップロード

- [ ] 独立したセクションとして表示する
- [ ] セクション内の上部に、現在参照している定義ファイルのパスを常に表示する（モックアップのためダミーパスをハードコードで表示）
- [ ] CSVファイルを選択できるファイル添付UIを表示する
- [ ] ファイル選択後、「アップロード」ボタンをクリックするとファイルを送信できる
- [ ] アップロード対象ファイルは CSV 形式のみ許可する
- [ ] CSVのカラム構成を以下の通りとする:
  - **標準マッピング行**: `CSVカラム名`, `種別（標準）`, `DBフィールド名`
  - **特別領域マッピング行**: `タイトル用CSVカラム名`, `種別（特別領域）`, `特別領域番号（1〜10）`, `値用CSVカラム名`

### 機能3: 変換定義内容表示

- [ ] 機能2と同一セクション内に「定義内容を表示」ボタンを設ける
- [ ] ボタンクリックで画面右側からオフキャンバスパネルが開く
- [ ] パネル内にキーワード絞り込み検索入力欄を表示する（`CSVカラム名` または `DBフィールド名 / 特別領域番号` で絞り込み）
- [ ] 絞り込み結果をテーブル形式で表示する（フォントサイズは body-s / 0.75rem）
- [ ] テーブルのカラム: `種別`, `CSVカラム名（タイトル用 / 標準）`, `DBフィールド名 / 特別領域番号`, `CSVカラム名（値用）`
  - 標準マッピング行は「CSVカラム名（値用）」列を空欄とする
- [ ] テーブルにはモックアップ用ダミーデータをハードコードで表示する（標準・特別領域を混在させて10件程度）

### 機能4: 雑コード変換テンプレート定義

- [ ] 独立したセクションとして表示する
- [ ] 雑コードの一覧をリスト形式で表示し、各エントリは以下の2フィールドを持つ:
  - **雑コード名**: ユーザーが入力できるテキストフィールド（例: `ZAT001`）
  - **テンプレート**: プレースホルダーを使ったテンプレートを入力できるテキストフィールド（例: `{品番}-{日付}`）
- [ ] 雑コード名はユーザーが自由に入力できる形式とする
- [ ] セクション下部に「エントリを追加」ボタンを設け、クリックするたびに新しい雑コード入力行（雑コード名＋テンプレートフィールドのペア）が追加できる
- [ ] 各エントリに「削除」ボタンを設け、不要な行を削除できる
- [ ] 初期表示時はダミーデータを3〜5件程度プリセットしておく（モックアップ用）
- [ ] テンプレートフィールドの下部（セクション共通）に、利用可能なプレースホルダー一覧を表示する
  - プレースホルダーは以下をサンプルとして定義する（実際のCSVカラムに対応）:
    - `{商品コード}` — ファイルの商品コード
    - `{品番}` — 品番
    - `{日付}` — 日付（YYYYMMDD形式）
    - `{数量}` — 数量
    - `{仕入先コード}` — 仕入先コード
  - 入力例: `{品番}-{日付}` → `A1234-20240401` のように変換される
- [ ] 入力内容を保存できる「保存」ボタンを表示する（モックアップのため保存動作はなし）
