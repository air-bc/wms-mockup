# [要件詳細] SCR-005: 入荷予定確定

> 非機能要件・プロジェクト概要は [renew_REQUIREMENTS.md](renew_REQUIREMENTS.md) を参照すること。
> 参考画面: [renew_REQUIREMENTS_SCR-003.md](renew_REQUIREMENTS_SCR-003.md)（テーブル・レイアウト構成を踏襲）

---

## 機能概要

入荷予定情報を確認・編集してから確定する画面。SCR-003（入荷予定一覧）と同じテーブル構成をベースに、各行の棚ロケーション・数量の編集と行取り消しが行える。

---

## 機能詳細

### 機能1: 日付フィルタ・最終更新日時表示

SCR-003 の機能1と同仕様。

- [ ] 日付を選択できる日付入力フォームを表示する（デフォルト値は翌日）
- [ ] 選択した日付に対応する入荷予定データをテーブルに表示する
- [ ] 最終更新日時をフォームの近くに表示する（モックアップのためダミー日時をハードコードで表示）

### 機能2: キーワード検索

SCR-003 の機能2と同仕様。

- [ ] 日付フィルタの近くにキーワード入力フィールドを1つ配置する
- [ ] 入力値による部分一致で、テーブルの表示行をリアルタイムにフィルタリングする
- [ ] 検索対象カラム: 伝票No・商品コード・商品名・入荷元・ロット番号
- [ ] 検索は大文字・小文字を区別しない
- [ ] 入力フィールドをクリアすると全件表示に戻る

### 機能3: 入荷予定確定テーブル

SCR-003 の機能3をベースに、以下を変更する。

- [ ] テーブルは SCR-003 と同じカラム構成に加え、左端に「選択」列、右端に「操作」列を追加する
- [ ] テーブルヘッダーはスクロール時も常に表示する（sticky）
- [ ] 「選択」列のヘッダーセルには全選択チェックボックス（`id="selectAllRows"`）を表示する
- [ ] 「選択」列の各行セルには行選択チェックボックス（クラス `row-checkbox`）を表示する
- [ ] 全選択チェックボックスをクリックすると、全行のチェックボックスを一括でオン/オフする
- [ ] 行チェックボックスの状態が変わると、全選択チェックボックスの状態（全オン/全オフ/不定）を更新する
- [ ] `棚ロケーション` セルは `<select>` で表示し、定義済み棚ロケ一覧から選択できる
- [ ] `数量` セルは `<input type="number">` で表示し、1以上の整数を入力できる
- [ ] 「操作」列に「取消」ボタンを表示する
- [ ] 「取消」ボタンをクリックすると対象行を取消状態にする
  - 行全体を半透明（`opacity: 0.4`）にする
  - テキストセルに打ち消し線を付ける（`text-decoration: line-through`）
  - `棚ロケーション` `数量` の入力を無効化する（`disabled`）
  - 行チェックボックスは引き続き操作可能のまま維持する
  - ボタンラベルを「取消解除」に変更し、スタイルを Subtle に切り替える
- [ ] 「取消解除」ボタンをクリックすると取消状態を解除し、通常状態に戻す
- [ ] 選択状態と取消状態の組み合わせによる表示は以下の通り
  - 通常・未選択: 背景色なし
  - 通常・選択済み: `background-selected`（薄い青）
  - 取消・未選択: `opacity: 0.4` + 打ち消し線
  - 取消・選択済み: `background-selected` + 打ち消し線（opacity は通常に戻す）

### 機能4: 確定ボタン

- [ ] テーブルセクションの見出し行（「入荷予定情報」テキストの右端）に「確定」ボタン（Primary）を表示する
- [ ] 確定ボタンは「チェックボックスで選択された行を確定する」ボタンとして動作する
- [ ] モックアップのため、クリック時の処理は不要

### JS 関数

| 関数名                              | 流用/新規 | 概要                                                           |
| ----------------------------------- | --------- | -------------------------------------------------------------- |
| `initScheduleDate()`                | 流用      | `#scheduleDate` のデフォルト値を翌日に設定                     |
| `initScheduleUpdatedAt()`           | 流用      | `#scheduleUpdatedAt` に現在日時を設定                          |
| `filterInboundScheduleTable(query)` | 流用      | `#inboundScheduleTable` の行を部分一致でフィルタリング         |
| `toggleRowCancel(btn)`              | 新規      | 取消/取消解除ボタンクリック時に行の取消状態をトグル            |
| `updateSelectAllState()`            | 新規      | 全行チェックボックスの状態に応じて全選択チェックボックスを更新 |
| `onSelectAllChange()`               | 新規      | 全選択チェックボックス変更時に全行を一括チェック               |
| `onRowCheckboxChange(checkbox)`     | 新規      | 行チェックボックス変更時に選択クラスをトグルし全選択状態を更新 |

#### `filterInboundScheduleTable` 対象セルのインデックス（0始まり）

左端に選択列（#0）が追加されたため、SCR-003 の値から +1 する。

| 伝票No | 商品コード | 商品名 | 入荷元 | ロット番号 |
| ------ | ---------- | ------ | ------ | ---------- |
| 3      | 4          | 5      | 7      | 10         |

#### `toggleRowCancel(btn)` 処理仕様

1. `btn` の最も近い `<tr>` を取得する
2. `<tr>` に `.schedule-row--cancelled` クラスをトグルする
3. 取消状態の場合:
   - `<tr>` 内の `<select>` と `<input type="number">` を `disabled` にする
   - `btn` のラベルを「取消解除」に変更し、`.schedule-cancel-btn` を外して `.schedule-restore-btn` を付ける
4. 取消解除の場合:
   - `<select>` と `<input type="number">` の `disabled` を解除する
   - `btn` のラベルを「取消」に変更し、`.schedule-restore-btn` を外して `.schedule-cancel-btn` を付ける
5. どちらの場合も `onRowCheckboxChange()` を呼び出して選択クラスと全選択状態を更新する

#### `onRowCheckboxChange(checkbox)` 処理仕様

1. `checkbox` の最も近い `<tr>` を取得する
2. チェックあり → `<tr>` に `.schedule-row--selected` を付与する
3. チェックなし → `<tr>` から `.schedule-row--selected` を除去する
4. `updateSelectAllState()` を呼び出す

#### `updateSelectAllState()` 処理仕様

1. 全行の `.row-checkbox` を全件取得する
2. 全件チェック済み → `#selectAllRows` を `checked: true`, `indeterminate: false` にする
3. 全件未チェック → `checked: false`, `indeterminate: false` にする
4. 一部チェック済み → `checked: false`, `indeterminate: true` にする

#### `onSelectAllChange()` 処理仕様

1. `#selectAllRows` の `checked` 値を取得する
2. 全行の `.row-checkbox` をすべてその値に設定し、各行の `.schedule-row--selected` クラスを同期する
