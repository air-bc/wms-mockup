# [要件詳細] SCR-011: 出荷確定

> 非機能要件・プロジェクト概要は [renew_REQUIREMENTS.md](renew_REQUIREMENTS.md) を参照すること。
> 参考画面: [renew_REQUIREMENTS_SCR-007.md](renew_REQUIREMENTS_SCR-007.md)（テーブル・レイアウト構成を踏襲）、[renew_REQUIREMENTS_SCR-005.md](renew_REQUIREMENTS_SCR-005.md)（確定画面の操作仕様を踏襲）

## 機能概要

<!-- [2026/05/26 修正要件により変更済み] 旧仕様は変更履歴参照 -->

出荷予定情報を確認してから確定する画面。受注Noを親行（グループ行）とし、その配下に複数の商品明細行を表示する2階層構成。商品明細行ごとに取消・棚ロケーション変更・数量変更・商品追加が行える。

---

## 機能詳細

### 機能1: 日付フィルタ・最終更新日時表示

SCR-007 の機能1と同仕様。

- [ ] 日付を選択できる日付入力フォームを表示する（デフォルト値は翌日）
- [ ] 選択した日付に対応する出荷予定データをテーブルに表示する
- [ ] 最終更新日時をフォームの近くに表示する（モックアップのためダミー日時をハードコードで表示）

### 機能2: キーワード検索

SCR-007 の機能2と同仕様。

- [ ] 日付フィルタの近くにキーワード入力フィールドを1つ配置する
- [ ] 入力値による部分一致で、テーブルの表示行をリアルタイムにフィルタリングする
- [ ] 検索対象カラム: 受注No・商品コード・商品名・出荷先・ロット番号 <!-- [2026/05/26 「伝票No」→「受注No」に変更] -->
- [ ] 検索は大文字・小文字を区別しない
- [ ] 入力フィールドをクリアすると全件表示に戻る

### 機能3: 出荷確定テーブル

<!-- [2026/05/26 修正要件により変更済み] 旧仕様は変更履歴参照 -->

テーブルは「受注グループ行」と「商品明細行」の2階層構成とする。

#### テーブル共通

- [ ] テーブルヘッダーはスクロール時も常に表示する（sticky）
- [ ] 「選択」列のヘッダーセルには全選択チェックボックス（`id="selectAllRows"`）を表示する（商品明細行を全選択対象とする）
- [ ] 全選択チェックボックスをクリックすると、全商品明細行のチェックボックスを一括でオン/オフする
- [ ] 商品明細行チェックボックスの状態が変わると、全選択チェックボックスの状態（全オン/全オフ/不定）を更新する

#### 受注グループ行（`<tr class="schedule-order-row">`）

- [ ] 受注Noを親行として表示し、その直後に配下の商品明細行を続けて表示する
- [ ] 受注グループ行には受注No・出荷予定日・出荷日時・出荷先・特記事項を表示する（読み取り専用）
- [ ] 受注グループ行の「操作」セルに「商品追加」ボタン（Default）を表示する
- [ ] 「商品追加」ボタンをクリックすると、対象グループの末尾に空の商品明細行を1行追加する

#### 商品明細行（`<tr class="schedule-item-row">`）

- [ ] 商品コード・商品名・棚ロケーション・数量・単位区分・ロット番号・賞味期限を表示する
- [ ] 「選択」列に行選択チェックボックス（クラス `row-checkbox`）を表示する
- [ ] `棚ロケーション` セルは選択式（`<select>` ドロップダウン）で編集可能とする
- [ ] `数量` セルは数値入力（`<input type="number">`）で編集可能とする
- [ ] 「操作」列に「取消」ボタン（Danger）を表示する
- [ ] 「取消」ボタンをクリックすると対象行を取消状態にする
  - 行全体を半透明（`opacity: 0.4`）にする
  - テキストセルに打ち消し線を付ける（`text-decoration: line-through`）
  - 行チェックボックス・入力フィールドは引き続き操作可能のまま維持する
  - ボタンラベルを「取消解除」に変更し、スタイルを Subtle に切り替える
- [ ] 「取消解除」ボタンをクリックすると取消状態を解除し、通常状態に戻す
- [ ] 選択状態と取消状態の組み合わせによる表示は以下の通り
  - 通常・未選択: 背景色なし
  - 通常・選択済み: `background-selected`（薄い青）
  - 取消・未選択: `opacity: 0.4` + 打ち消し線
  - 取消・選択済み: `background-selected` + 打ち消し線（opacity は通常に戻す）

### 機能4: 確定ボタン

- [ ] テーブルセクションの見出し行（「出荷予定情報」テキストの右端）に「確定」ボタン（Primary）を表示する
- [ ] 確定ボタンは「チェックボックスで選択された行を確定する」ボタンとして動作する
- [ ] モックアップのため、クリック時の処理は不要

### レイアウト実現方式（CSS Flexbox + ページ固有クラス）

SCR-007 と同じ実現方式を流用する。JS による高さ計算は使用しない。

| セレクタ                                | 設定値                                                    | 目的                                          |
| --------------------------------------- | --------------------------------------------------------- | --------------------------------------------- |
| `html, .schedule-page`                  | `height: 100%; overflow: hidden`                          | ページスクロール抑制                          |
| `.schedule-page .app-layout`            | `height: 100%`                                            | `.app-layout` の `min-height: 100vh` を上書き |
| `.schedule-page .app-body`              | `overflow: hidden`                                        | 縦方向伸張防止                                |
| `<main class="app-main schedule-main">` | `display: flex; flex-direction: column; overflow: hidden` | 縦 Flex コンテナ化                            |
| コントロール行                          | `flex-shrink: 0`                                          | 高さ固定                                      |
| `.schedule-table-wrapper`               | `flex: 1; overflow: auto; min-height: 0`                  | テーブル部分のみスクロール                    |
| `thead th`                              | `position: sticky; top: 0; z-index: 1`                    | ヘッダー固定                                  |

| `filterOutboundScheduleTable(query)` | 流用      | `#outboundScheduleTable` の商品明細行（`.schedule-item-row`）を部分一致でフィルタリング。受注グループ行は常に表示                                         |
| `toggleRowCancel(btn)`               | 流用      | 取消/取消解除ボタンクリック時に商品明細行の取消状態をトグル（SCR-005 で定義済み）。棚ロケーション・数量の入力は取消状態でも操作可能のまま維持             |
| `onRowCheckboxChange(checkbox)`      | 流用      | 行チェックボックス変更時に選択クラスをトグルし全選択状態を更新（SCR-005 で定義済み）                                                                      |
| `updateSelectAllState()`             | 流用      | 全商品明細行チェックボックスの状態に応じて全選択チェックボックスを更新（SCR-005 で定義済み）                                                              |
| `onSelectAllChange()`                | 流用      | 全選択チェックボックス変更時に全商品明細行を一括チェック（SCR-005 で定義済み）                                                                            |
| `addProductToOrder(btn)`             | 新規      | 「商品追加」ボタン押下時: `data-order-id` で対象グループを特定し、最後の商品明細行の直後に空の `.schedule-item-row` を1行挿入する。取消・選択状態は未設定 |

#### `filterOutboundScheduleTable` 検索対象

商品明細行（`.schedule-item-row`）のみ対象。受注グループ行（`.schedule-order-row`）は常に表示する。

| 受注No（グループ行） | 商品コード | 商品名    | 出荷先（グループ行） | ロット番号 |
| -------------------- | ---------- | --------- | -------------------- | ---------- |
| グループ行セル #1    | 明細行 #5  | 明細行 #6 | グループ行セル #4    | 明細行 #10 |
