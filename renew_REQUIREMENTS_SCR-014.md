# [要件詳細] SCR-014: 在庫管理

> 非機能要件・プロジェクト概要は [renew_REQUIREMENTS.md](renew_REQUIREMENTS.md) を参照すること。

---

## 機能概要

商品コード × ロット番号 × 賞味期限 × 入庫日単位で在庫数量を集計した一覧を表示する画面（棚ロケが異なる同一ロットは数量を合算）。キーワードでフィルタリングしながら一覧表示し、ページネーションで表示件数を制限する。各行をクリックするとモーダルが開き、そのロットの棚ロケ別内訳を確認できる。

---

## 機能詳細

### 機能1: キーワード検索

- [ ] キーワード入力フィールドを1つ配置する
- [ ] 入力値による部分一致で、テーブルの表示行をリアルタイムにフィルタリングする
- [ ] 検索対象カラム: 商品コード・商品名・ロット番号
- [ ] 検索は大文字・小文字を区別しない
- [ ] 入力フィールドをクリアすると全件表示に戻る

### 機能2: 在庫一覧テーブル

- [ ] 在庫データをテーブル形式で表示する（モックアップのためダミーデータをハードコードで表示、計25件）
- [ ] テーブルヘッダーはスクロール時も常に表示する（sticky）
- [ ] テーブルのカラム:
  - `商品コード`
  - `商品名`
  - `ロット番号`
  - `数量`
  - `単位区分`
  - `賞味期限`
  - `入庫日`
  - `特記`（アイコン）
- [ ] 行クリックで対応する棚ロケ別内訳モーダルを開く（カーソルは `pointer`）

> カラム記載基準
>
> - `数量`: 同一（商品コード × ロット番号 × 賞味期限 × 入庫日）の全棚ロケの在庫数量合計
> - `単位区分`: パレット・ケース・ボール・ピースなど。未定義の場合は `‐` を表示
> - `賞味期限`: 未定義の場合は `‐` を表示
> - `特記`: そのロットのいずれかの棚ロケに特記事項が存在する場合にアイコン（●）を表示

### 機能3: ページネーション

- [ ] 1ページあたり **20件** 表示する
- [ ] テーブル下部にページネーションコンポーネントを表示する
- [ ] テーブルセクション見出しの左側に **「全 XX 件」** の件数表示を行う（フィルタ適用後の件数を反映）
- [ ] ページネーションの構成: `[< 前へ]` `[ページ番号ボタン]` `[次へ >]`
- [ ] 現在ページのボタンはアクティブ状態で表示する
- [ ] 前へ・次へボタンは端ページで無効化する
- [ ] キーワードでフィルタリングした際は1ページ目に戻る

### 機能4: 棚ロケ別内訳モーダル

- [ ] テーブルの行をクリックするとモーダルを開く
- [ ] モーダルヘッダー: 商品コード・商品名・ロット番号・賞味期限・入庫日を表示する
- [ ] モーダル内テーブルのカラム:
  - `棚ロケーション`
  - `数量`
  - `特記事項`
- [ ] モーダル外クリックまたは閉じるボタンでモーダルを閉じる

#### `filterInventoryList` のロジック

1. `#inventoryListSearch` のキーワードを取得
2. ダミーデータ全25件に対して:
   - キーワードが入力済み → 商品コード・商品名・ロット番号に部分一致する行のみ残す（大文字・小文字を区別しない）
3. 結果を `currentFiltered` に保持し、`renderInventoryListPage(1)` を呼ぶ

#### ページネーション表示ロジック

ダミーデータ25件・20件/ページのため最大2ページ。省略（`...`）表示は不要。全ページ番号を列挙する。

| 条件            | `[< 前へ]` | `[次へ >]` |
| --------------- | ---------- | ---------- |
| 1ページ目       | `disabled` | 有効       |
| 最終ページ      | 有効       | `disabled` |
| 1ページしかない | `disabled` | `disabled` |
