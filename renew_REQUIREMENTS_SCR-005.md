# [要件詳細] SCR-004: 入荷予定登録

> 非機能要件・プロジェクト概要は [renew_REQUIREMENTS.md](renew_REQUIREMENTS.md) を参照すること。
> 旧ドキュメント参照: `archive/REQUIREMENTS_SCR-001.md` 機能1「入荷事前情報アップロード」

---

## 機能概要

入荷予定情報をCSVアップロードまたは手動入力で登録する画面。

> **モックアップ方針**: アップロード成功/失敗等のフィードバックメッセージは表示しない。アップロード後の画面遷移も不要。

---

## 機能詳細

### 機能1: 入荷事前情報CSVアップロード

- [ ] CSVファイルを選択できるファイル添付UIを表示する
- [ ] アップロード対象ファイルは CSV 形式のみ許可する（`accept=".csv"`）
- [ ] ファイル選択後、「アップロード」ボタンをクリックするとファイルを送信できる（モックアップのため実際の送信処理は不要）

### 機能2: 手動入力フォーム

- [ ] CSVアップロードセクションの下に手動入力フォームを表示する
- [x] ~~フォームのフィールド構成（伝票・商品項目をすべて単一行で構成）~~ [2026/07/01 修正要件により変更済み: 伝票単位フィールドと商品明細（複数行）に分離]
- [x] ~~1入荷予定（伝票）に対して商品明細は1件のみとする（1オーダー1商品）~~ [2026/07/01 修正要件により撤回: SCR-010（出荷予定登録）と同様、1伝票に複数の商品明細を登録できる方式に変更]

> **参考**: `wms/inbound/models.py` の `InboundSchedule`（伝票）1 に対し `InboundScheduleItem`（明細）多の構成、および `開発資料/D_画面仕様.md` の `/inbound/schedules/new/` 記載に準拠する。
