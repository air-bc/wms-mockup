# [要件詳細] SCR-009: 出荷予定登録

> 非機能要件・プロジェクト概要は [renew_REQUIREMENTS.md](renew_REQUIREMENTS.md) を参照すること。

---

## 機能概要

出荷予定情報をCSVアップロードまたは手動入力で登録する画面。

> **モックアップ方針**: アップロード成功/失敗等のフィードバックメッセージは表示しない。アップロード後の画面遷移も不要。

---

## 機能詳細

### 機能1: 出荷予定CSVアップロード

- [ ] CSVファイルを選択できるファイル添付UIを表示する
- [ ] アップロード対象ファイルは CSV 形式のみ許可する（`accept=".csv"`）
- [ ] ファイル選択後、「アップロード」ボタンをクリックするとファイルを送信できる（モックアップのため実際の送信処理は不要）

### 機能2: 手動入力フォーム

<!-- [2026/05/26 修正要件により変更済み] 旧仕様は変更履歴参照 -->

- [ ] CSVアップロードセクションの下に手動入力フォームを表示する
- [ ] フォームは「伝票単位フィールド」と「商品明細行」の2段構成とする
- [ ] **伝票単位フィールド**（1伝票につき1つ）:

| フィールド | 入力種別 | 必須 | 備考                            |
| ---------- | -------- | ---- | ------------------------------- |
| 出荷予定日 | date     | ○    |                                 |
| 受注No     | text     | ○    | [2026/05/26 「伝票No」から変更] |
| 出荷先     | text     | ○    |                                 |
| 特記事項   | text     |      |                                 |

- [ ] **商品明細行**（1伝票につき複数追加可能）:

| フィールド     | 入力種別 | 必須 | 備考                                       |
| -------------- | -------- | ---- | ------------------------------------------ |
| 商品コード     | text     | ○    |                                            |
| 商品名         | text     | ○    |                                            |
| 棚ロケーション | text     |      |                                            |
| 数量           | number   | ○    | 1以上の整数                                |
| 単位区分       | select   |      | パレット・ケース・ボール・ピース。未選択可 |
| ロット番号     | text     |      |                                            |
| 賞味期限       | date     |      |                                            |

- [ ] 商品明細行の操作:
  - 初期表示: 1行表示
  - **「行追加」ボタン**: 商品明細行を1行追加する
  - **「行削除」ボタン**（各行右端）: 該当行を削除する。ただし最低1行は残す
- [ ] ボタンを2種類表示する:
  - **「登録して続ける」**: フォームを部分的にリセットし、同画面に留まる
  - **「登録する」**: フォームを送信後、SCR-007（出荷予定一覧）へ遷移する
- [ ] 「登録して続ける」押下後の引き継ぎ挙動:
  - 引き継ぐ項目: 出荷予定日・受注No・出荷先
  - クリアする項目: 特記事項・商品明細行（全行リセット → 1行に戻す）

### フォームフィールドレイアウト

<!-- [2026/05/26 修正要件により変更済み] -->
<!-- [2026/05/26 商品明細をテーブル形式に変更] -->

#### 伝票単位フィールド（2カラムグリッド）

| 左カラム         | 右カラム |
| ---------------- | -------- |
| 出荷予定日       | 受注No   |
| 出荷先           | （空）   |
| 特記事項（全幅） | —        |

#### 商品明細（テーブル形式・1商品 = 1行）

ヘッダー行（列ラベル）を1行設け、以降の各商品を1行で表示する。縦スクロールを最小化するため全フィールドを横並びにする。

| 列  | フィールド     | 幅（grid列定義）    | 備考                       |
| --- | -------------- | ------------------- | -------------------------- |
| 1   | 商品コード     | `100px`             | 必須                       |
| 2   | 商品名         | `1fr`（最小 120px） | 必須                       |
| 3   | 棚ロケーション | `90px`              |                            |
| 4   | 数量           | `70px`              | 必須・1以上の整数          |
| 5   | 単位区分       | `90px`              | セレクト。未選択可         |
| 6   | ロット番号     | `110px`             |                            |
| 7   | 賞味期限       | `130px`             | date picker                |
| 8   | （行削除）     | `44px`              | ×ボタン。最低1行は削除不可 |

- grid-template-columns: `100px 1fr 90px 70px 90px 110px 130px 44px`
- ヘッダー行と入力行は同一の grid-template-columns を持ち、列が揃う
- 明細行エリア下部に「＋ 行追加」ボタンを右寄せで配置する
