# [要件詳細] SCR-018: 棚卸管理

> 非機能要件・プロジェクト概要は [renew_REQUIREMENTS.md](renew_REQUIREMENTS.md) を参照すること。

---

## 機能概要

棚卸の開始・進捗確認・承認・完了を管理する画面。スマートフォンで入力された棚卸結果をPC画面で確認し、棚ロケ単位で承認する。全棚ロケの承認完了後に棚卸全体を完了できる。

---

## 操作フロー

```text
[1] 「棚卸開始」ボタンをクリック
    ↓
[2] 全棚ロケの一覧が表示される（全行「未着手」状態）
    スマートフォン側で棚卸入力が進むと行が「進行中」→「完了」に変化する
    ↓
[3] 「更新」ボタンで最新状態を取得（または最終更新日時を確認）
    ↓
[4] 「完了」状態の棚ロケ行のチェックボックスをオンにする（複数選択可）
    ↓
[5] 「承認」ボタンをクリック → 選択行が「承認済み」状態になる
    ↓ 繰り返し（全棚ロケが「承認済み」になるまで）
[6] 全棚ロケが「承認済み」になると「棚卸完了」ボタンが有効化される
    ↓
[7] 「棚卸完了」ボタンをクリック → 在庫数が棚卸入力値で確定・更新される
    フラッシュメッセージ「棚卸が完了しました」を表示
```

## 機能詳細

### 機能1: 棚卸開始

- [ ] 「棚卸開始」ボタンを画面上部に配置する
- [ ] 棚卸開始前は、棚ロケ一覧を表示せず案内文「棚卸を開始するには「棚卸開始」ボタンをクリックしてください。」を表示する
- [ ] 「棚卸開始」ボタンをクリックすると、全棚ロケ一覧を表示する
- [ ] 棚卸開始後は「棚卸開始」ボタンを非活性にする

### 機能2: 棚ロケ一覧

- [ ] 棚ロケ一覧をテーブル形式で表示する（モックアップのためダミーデータをハードコードで表示、計15件程度）
- [ ] テーブルヘッダーはスクロール時も常に表示する（sticky）
- [ ] テーブルのカラム:

| カラム           | 内容                                                                             |
| ---------------- | -------------------------------------------------------------------------------- |
| チェックボックス | 行選択。「完了」状態の行のみ有効（それ以外は `disabled`）                        |
| 棚ロケ           | 棚ロケコード                                                                     |
| 状態             | 未着手 / 進行中 / 完了 / 承認済み（状態バッジで表示）                            |
| 差異             | 「完了」以降の行のみ表示。差異がある場合は「⚠ 差異あり」、ない場合は「差異なし」 |

- [ ] 状態バッジの配色:

| 状態     | カラーロール  |
| -------- | ------------- |
| 未着手   | `neutral`     |
| 進行中   | `information` |
| 完了     | `warning`     |
| 承認済み | `success`     |

- [ ] 差異ありの「⚠ 差異あり」バッジは `warning` ロールで表示する

### 機能3: インライン展開（商品詳細）

<!-- [2026/05/25 修正] 展開対象を全状態に拡大。棚卸数量・差異の表示は状態依存に変更 -->

- [ ] 棚ロケ行をクリックすると、行の下にインラインで商品詳細を展開する
- [ ] ~~展開対象は「完了」または「承認済み」状態の行のみ。「未着手」「進行中」はクリックしても展開しない~~  
       **[2026/05/25 変更済み]** 展開対象はすべての状態の行。状態によらずクリックで展開できる
- [ ] 再クリックで折りたたむ
- [ ] 展開中の行は視覚的に区別できるようにする（例: 行背景を `color.background.selected` に変更）
- [ ] 展開エリアのカラム:

| カラム     | 内容                                                                                                  |
| ---------- | ----------------------------------------------------------------------------------------------------- |
| 商品コード | -                                                                                                     |
| 商品名     | -                                                                                                     |
| ロット番号 | -                                                                                                     |
| 棚卸数量   | 「進行中」「完了」「承認済み」の場合のみ実数値を表示。「未着手」の場合は `—` を表示                   |
| 現在在庫数 | 棚卸前の在庫数量                                                                                      |
| 差異       | 「進行中」「完了」「承認済み」の場合のみ計算・表示（正: `+n`、負: `-n`、ゼロ: `0`）。「未着手」は `—` |
| 単位区分   | -                                                                                                     |

- [ ] 差異が 0 でない行は差異セルを `warning` ロールで強調表示する
- [ ] 1つの棚ロケに複数の商品（商品コード・ロット番号の組み合わせ）が存在する場合、複数行を表示する

### 機能4: 更新

- [ ] 「更新」ボタンを画面上部（棚卸状態の操作エリア）に配置する
- [ ] 「最終更新日時: YYYY/MM/DD HH:MM:SS」を更新ボタンの隣に表示する
- [ ] 「更新」ボタンをクリックするとダミーデータで状態を再反映し、最終更新日時を現在時刻に更新する（モックアップ）

### 機能5: 承認

- [ ] 「承認」ボタンを画面上部に配置する
- [ ] チェックボックスが1件以上選択されていない場合、「承認」ボタンを非活性にする
- [ ] 「承認」ボタンをクリックすると、選択行の状態を「承認済み」に変更する
- [ ] 承認後、チェックボックスの選択をすべて解除する
- [ ] 承認によってすべての棚ロケが「承認済み」になった場合、「棚卸完了」ボタンを有効化する

### 機能6: 棚卸完了

- [ ] 「棚卸完了」ボタンを画面上部に配置する
- [ ] 全棚ロケが「承認済み」状態でない場合、「棚卸完了」ボタンを非活性にする
- [ ] モックアップでは、棚卸開始後すぐに非活性、全棚ロケが承認済みになるとアクティブに切り替わるデモ動作を実装する
- [ ] 「棚卸完了」ボタンをクリックすると確認ダイアログを表示する
  - ダイアログ内容:「棚卸を完了します。在庫数が棚卸入力値で更新されます。よろしいですか？」
  - ボタン: 「完了」 / 「キャンセル」
- [ ] 「完了」をクリックするとフラッシュメッセージ「棚卸が完了しました」を表示し、画面を初期状態（棚卸開始前）に戻す

### JS 関数

#### 状態変数

| 変数名               | 初期値      | 型              | 用途                                     |
| -------------------- | ----------- | --------------- | ---------------------------------------- |
| `inventoryStarted`   | `false`     | `boolean`       | 棚卸開始済みか                           |
| `inventoryLocations` | `[]`        | `Array<Object>` | 棚ロケデータ（状態・チェック状態を含む） |
| `expandedLocations`  | `new Set()` | `Set<string>`   | 展開中の棚ロケコードセット               |
| `refreshCount`       | `0`         | `number`        | 更新ボタン押下回数（デモ用状態進行制御） |

各棚ロケオブジェクトのプロパティ:

```js
{
  location: string,       // 棚ロケコード
  status: string,         // 'pending' | 'in_progress' | 'done' | 'approved'
  checked: boolean,       // チェックボックス状態
  items: Array<{
    itemCode: string,
    itemName: string,
    lotNo: string,
    countQty: number,     // 棚卸数量
    stockQty: number,     // 現在在庫数
    unit: string
  }>
}
```

---

#### 関数

| 関数名                            | 流用/新規 | 概要                                                                                                                           |
| --------------------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `initInventory()`                 | 新規      | ダミーデータで `inventoryLocations` を初期化する（status: 'pending'）                                                          |
| `startInventory()`                | 新規      | `inventoryStarted = true`・案内文非表示・テーブルエリア表示・開始ボタン無効化・`renderInventoryTable()` 呼び出し               |
| `renderInventoryTable()`          | 新規      | `inventoryLocations` を元にテーブルを再描画する                                                                                |
| `toggleLocationDetail(location)`  | 新規      | `expandedLocations` に追加/除去し、該当行の展開/折りたたみを切り替える                                                         |
| `refreshInventory()`              | 新規      | `refreshCount` をインクリメント・状態進行ロジックを実行・再描画・最終更新日時を現在時刻に更新                                  |
| `advanceStatus()`                 | 新規      | `refreshCount` の値に応じて棚ロケの状態を段階的に進行させる（下記参照）                                                        |
| `approveSelected()`               | 新規      | `checked: true` の行を `status: 'approved'` に変更・チェック解除・再描画・ボタン状態更新                                       |
| `validateApproveBtn()`            | 新規      | チェック済み行が1件以上あれば承認ボタンを有効化する                                                                            |
| `validateCompleteBtn()`           | 新規      | 全棚ロケが `status: 'approved'` であれば棚卸完了ボタンを有効化する                                                             |
| `completeInventory()`             | 新規      | ダイアログ「完了」後: フラッシュメッセージ表示・`initInventory()` で初期化・テーブルエリア非表示・案内文表示・開始ボタン有効化 |
| `showFlashMessage(message, type)` | 流用      | フラッシュメッセージを表示し3秒後に自動消去する                                                                                |

#### `advanceStatus` のロジック（デモ用）

`refreshCount` の値に応じて、以下の順で状態を進行させる。承認済み（`approved`）の行は変更しない。

| `refreshCount` | 状態変化                                                                        |
| -------------- | ------------------------------------------------------------------------------- |
| 1              | A棟（A-01-01〜A-02-02）: `pending` → `in_progress`                              |
| 2              | A棟: `in_progress` → `done`、B棟（B-01-01〜B-02-02）: `pending` → `in_progress` |
| 3              | B棟: `in_progress` → `done`、C棟（C-01-01〜C-02-02）: `pending` → `in_progress` |
| 4              | C棟: `in_progress` → `done`、D棟（D-01-01〜D-02-02）: `pending` → `in_progress` |
| 5 以上         | D棟: `in_progress` → `done`                                                     |
