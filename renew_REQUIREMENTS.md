## 1. プロジェクト概要

倉庫管理システム（WMS）のUIモックアップ。画面遷移・レイアウト・操作フローを静的HTMLで再現し、ステークホルダーへの提示と仕様確認を目的とする。

## 3.2 共通UI仕様

### サイドメニュー

#### タイトル

- [x] ~~サイドメニューのタイトルラベルは「モックアップメニュー」とする~~ [2026/05/25 廃止: タイトルラベルを表示しない方針に変更]

#### サブ画面のメニュー表示

- [ ] サイドメニューには、トップレベルの画面のみを通常の項目として表示する
- [ ] サブ画面のメニュー項目は**すべてのページで常時表示**する（折りたたみなし）
- [ ] サブ画面項目には右矢印アイコンを付ける
- [ ] サブ画面項目は、親項目からインデントが分かる見た目にする（縦線は表示しない）
- [ ] サブ画面にいる場合、対応するサブ項目をアクティブ状態にする

```text
例: 在庫明細を表示中のサイドメニュー
  各種ファイル連携
  ...
  在庫管理（在庫一覧）
    › 在庫明細        ← アクティブ
    › 移動履歴
```

#### グルーピング表示

- [ ] サイドメニューの項目はグループに分類し、グループ名をヘッダーとして表示する
- [ ] グループ構成・表示順・各グループの項目は §3.1 の画面一覧に従う

```text
【マスター定義】
  棚ロケ定義（SCR-001）
  商品マスタ（SCR-002）
  取引先マスタ（SCR-003）
【入荷管理】
  入荷予定一覧（SCR-004）
    › 入荷予定登録（SCR-005）
    › 入荷予定確定（SCR-006）
    › 入荷登録（SCR-007）
  入荷履歴（SCR-008）
【出荷管理】
  出荷予定一覧（SCR-009）
    › 出荷予定登録（SCR-010）
    › 引き当てチェック（SCR-011）
    › 出荷確定（SCR-012）
  出荷履歴（SCR-013）
【在庫管理】
  在庫管理（SCR-014）
    › 在庫管理（棚ロケ別）（SCR-015）
  在庫調整（SCR-016）
  棚ロケ移動登録（SCR-017）
  棚ロケ移動履歴（SCR-018）
【棚卸】
  棚卸管理（SCR-019）
  棚卸数更新履歴（SCR-020）
```

- [ ] 要件定義前の画面（SCR-003・SCR-016・SCR-019〜020）も通常表示し、リンク先は `#` とする

### 日付・時刻入力フィールドの操作性

- [ ] `<input type="date">` および `<input type="time">` のフィールドは、**枠内のどこをクリックしてもブラウザ標準のピッカーが起動**するようにする
- [ ] 実装方法：フィールド全体に `showPicker()` を呼び出す `click` イベントリスナーを付与する
- [ ] 対象：`renew_templates/` 配下のすべてのHTMLファイルに共通適用する

#### 設計

| 項目           | 内容                                                                                          |
| -------------- | --------------------------------------------------------------------------------------------- |
| 実装ファイル   | `static/js/main.js`（全HTMLで共通読み込み済み）                                               |
| 処理タイミング | `DOMContentLoaded` イベント内                                                                 |
| 対象セレクタ   | `input[type="date"], input[type="time"]`                                                      |
| 処理内容       | 各要素に `click` イベントリスナーを付与し `showPicker()` を呼び出す                           |
| エラー処理     | `showPicker()` は非ユーザー操作起点で `InvalidStateError` を投げるため `try-catch` で保護する |

### 付箋メモ機能

- [ ] `renew_templates/` 配下のすべての画面に付箋メモ機能を共通適用する
- [ ] 実装詳細は [renew_REQUIREMENTS_STICKY.md](renew_REQUIREMENTS_STICKY.md) を参照すること

### スマートフォン画面のモックアップ表示方針

スマートフォンで操作する画面（検品系・棚移動系等）はモックアップとして以下の方針で実装する。

- [ ] PC のメイン領域中央に縦長の枠（スマートフォン画面を模したフレーム）を表示し、その中にコンテンツを描画する
- [ ] フレームのサイズ・デザインは renew_DESIGN.md に定義する
- [ ] PC のメイン領域背景色を**彩度0の暗色**にし、スマートフォンフレームが白く浮き上がって見えるようにする（グレー〜黒系。ブランドカラーの緑系は使用しない）

## 4. 非機能要件

| 分類             | 要件                                                                                                              |
| ---------------- | ----------------------------------------------------------------------------------------------------------------- |
| 実装方式         | **HTML/CSS/JavaScript のみ**で構築する。サーバーサイド不要。ブラウザでHTMLファイルを直接開いて確認できること      |
| デザイン         | **Atlassian Design System**（https://atlassian.design/）に完全準拠したUIとする                                    |
| デザイン詳細     | CSSカスタムプロパティ（`var(--ds-xxx)`）によるデザイントークンを使用し、HEX値・px値の直書きを禁止する             |
| スペーシング     | 8pxグリッドに基づくスペーシングスケール（`space.100` = 8px 等）を遵守する                                         |
| タイポグラフィ   | フォントサイズは `rem` 単位で指定。本文デフォルトは Body M（0.875rem / 14px）とする                               |
| エレベーション   | カード等の浮き上がり表現は `elevation.surface.raised` + `elevation.shadow.raised` をペアで使用する                |
| カラーロール     | 状態表現には `success` / `warning` / `danger` / `information` のロールを正しく使い分ける                          |
| アクセシビリティ | セマンティックHTML（`<header>`, `<nav>`, `<main>` 等）を使用し、コントラスト比は通常テキスト 4.5:1 以上を確保する |
| テーマ           | ライトモードのみ対応する                                                                                          |
| 対応ブラウザ     | Chrome 最新版                                                                                                     |
| レスポンシブ     | デスクトップ（1280px以上）を優先。Atlassianブレイクポイント（30rem, 48rem, 64rem, 90rem）を考慮する               |
| コーディング規約 | HTML の `id` 属性は **camelCase** で記述する（例: `mainContent`, `scheduleDate`）                                 |
| ファイル配置     | HTMLファイルは `renew_templates/` ディレクトリに配置する                                                          |
