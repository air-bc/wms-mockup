# [要件詳細] SCR-017: 棚ロケ移動履歴

> 非機能要件・プロジェクト概要は [renew_REQUIREMENTS.md](renew_REQUIREMENTS.md) を参照すること。

---

## 機能概要

SCR-016（棚ロケ移動登録）で登録した棚ロケ間の在庫移動履歴を一覧表示する画面。日付範囲・キーワードでフィルタリングしながら参照でき、ページネーションで表示件数を制限する。

---

## 機能詳細

### 機能1: 日付範囲フィルタ

- [ ] 開始日・終了日の2つの日付入力フォームを表示する（デフォルト値は空欄）
- [ ] 開始日と終了日は `移動日 [____] ～ [____]` の形式で横並びに表示する（「移動日」ラベル + 開始日 input + ～ + 終了日 input）
- [ ] 開始日を指定した場合、その日付以降のデータに絞り込む
- [ ] 終了日を指定した場合、その日付以内（終了日を含む）のデータに絞り込む
- [ ] 両方を空欄にした場合は全件表示する
- [ ] フィルタはキーワード検索と組み合わせて適用する

### 機能2: キーワード検索

- [ ] 日付範囲フィルタの近くにキーワード入力フィールドを1つ配置する
- [ ] 入力値による部分一致で、テーブルの表示行をリアルタイムにフィルタリングする
- [ ] 検索対象カラム: 棚ロケ（元）・棚ロケ（先）・商品コード・商品名・ロット番号
- [ ] 検索は大文字・小文字を区別しない
- [ ] 入力フィールドをクリアすると全件表示に戻る
- [ ] キーワード検索は日付範囲フィルタと組み合わせて適用する

### 機能3: 移動履歴テーブル

- [ ] 棚ロケ移動履歴データをテーブル形式で表示する（モックアップのためダミーデータをハードコードで表示、計25件）
- [ ] テーブルヘッダーはスクロール時も常に表示する（sticky）
- [ ] テーブルセクション見出し行の右端に **PDFダウンロードボタン**を配置する（クリックしても動作不要）
- [ ] テーブルのカラム:
  - `移動日時`（`yyyy/mm/dd hh:mm` 形式）
  - `棚ロケ（元）`
  - `棚ロケ（先）`
  - `商品コード`
  - `商品名`
  - `ロット番号`
  - `移動数量`
  - `単位区分`
  - `特記事項`

> カラム記載基準
>
> - `移動数量`: 1以上の数値
> - `単位区分`: パレット・ケース・ボール・ピースなど。未定義の場合は `‐` を表示

### 機能4: ページネーション

- [ ] 1ページあたり **20件** 表示する
- [ ] テーブル下部にページネーションコンポーネントを表示する
- [ ] テーブルセクション見出しの左側に **「全 XX 件」** の件数表示を行う（フィルタ適用後の件数を反映）
- [ ] ページネーションの構成: `[< 前へ]` `[ページ番号ボタン]` `[次へ >]`
- [ ] 現在ページのボタンはアクティブ状態で表示する
- [ ] 前へ・次へボタンは端ページで無効化する
- [ ] 日付範囲またはキーワードでフィルタリングした際は1ページ目に戻る

### レイアウト実現方式

`schedule-page` CSS スコープ（`overflow: hidden` によるページスクロール抑制）は**使用しない**。ページネーションで行数を制限するため、テーブル内スクロールは不要。通常フローでページ全体がスクロールする。

| 要素                      | 設定                           | 備考                          |
| ------------------------- | ------------------------------ | ----------------------------- |
| `<body>`                  | クラス追加なし                 | `.schedule-page` は適用しない |
| `<main class="app-main">` | 通常フロー                     | `overflow: visible`           |
| `.history-table-wrapper`  | `overflow-x: auto` のみ        | 縦は制限しない                |
| `thead th`                | `position: sticky; top: 0`     | 横スクロール時もヘッダー固定  |
| ページネーション          | テーブル下部に `flex` 中央揃え | カード外・メイン領域内に配置  |

### JS 関数

#### 状態変数

| 変数名                        | 初期値   | 型              | 用途                                   |
| ----------------------------- | -------- | --------------- | -------------------------------------- |
| `transferHistoryDummyData`    | 25件配列 | `Array<Object>` | ダミーデータ（ページ読み込み時に定義） |
| `transferHistoryFilteredData` | `[]`     | `Array<Object>` | フィルタリング後の全件データ           |
| `transferHistoryCurrentPage`  | `1`      | `number`        | 現在のページ番号                       |
| `transferHistoryItemsPerPage` | `20`     | `number`        | 1ページあたりの表示件数                |

各行オブジェクトのプロパティ: `{ datetime, srcLocation, destLocation, itemCode, itemName, lotNo, qty, unit, note }`

#### 関数

| 関数名                                   | 流用/新規 | 概要                                                                                |
| ---------------------------------------- | --------- | ----------------------------------------------------------------------------------- |
| `initTransferHistory()`                  | 新規      | ダミーデータを `transferHistoryFilteredData` にセットして初期描画を行う             |
| `filterTransferHistory()`                | 新規      | 日付範囲・キーワードを組み合わせて `transferHistoryFilteredData` を更新し再描画する |
| `renderTransferHistoryTable(page)`       | 新規      | 指定ページのデータをテーブルに描画する                                              |
| `renderTransferHistoryPagination()`      | 新規      | フィルタ後の全件数から総ページ数を計算しページネーションを描画する                  |
| `updateTransferHistoryTotalCount(count)` | 新規      | `#transferHistoryTotalCount` に件数を表示する                                       |
| `goToTransferHistoryPage(page)`          | 新規      | `transferHistoryCurrentPage` を更新して `renderTransferHistoryTable` を呼ぶ         |

#### フィルタロジック（`filterTransferHistory`）

1. `#transferHistoryDateFrom` / `#transferHistoryDateTo` の値（`"YYYY-MM-DD"` 形式、未入力時は `""`）を取得する
2. `#transferHistoryKeyword` の値を取得する（小文字化）
3. ダミーデータ全25件に対して以下の条件でフィルタリングする:
   - 開始日が指定されていれば `datetime` の日付部分（`"2026/05/19"` → `"2026-05-19"` に変換）が `>=` 開始日の行を残す
   - 終了日が指定されていれば同様に変換後 `<=` 終了日の行を残す
   - キーワードが入力されていれば、`srcLocation` / `destLocation` / `itemCode` / `itemName` / `lotNo` のいずれかに部分一致する行を残す
4. 結果を `transferHistoryFilteredData` に保持する
5. `transferHistoryCurrentPage = 1` にリセットする
6. `updateTransferHistoryTotalCount(transferHistoryFilteredData.length)` を呼ぶ
7. `renderTransferHistoryTable(1)` と `renderTransferHistoryPagination()` を呼ぶ

> 日付比較の変換: `"2026/05/19"` → `"2026-05-19"`（`replace(/\//g, '-')`）

#### `renderTransferHistoryTable(page)` のロジック

1. `start = (page - 1) * transferHistoryItemsPerPage`、`end = start + transferHistoryItemsPerPage` を計算する
2. `transferHistoryFilteredData.slice(start, end)` で表示行を取り出す
3. `#transferHistoryTableBody` の innerHTML をクリアし、取り出した行を `<tr>` として描画する
4. 表示行が0件の場合は「データがありません」と表示する `<tr>` を1行描画する

#### `renderTransferHistoryPagination()` のロジック

1. `totalPages = Math.ceil(transferHistoryFilteredData.length / transferHistoryItemsPerPage)` を計算する
2. `#transferHistoryPagination` の innerHTML をクリアする
3. `[< 前へ]` ボタンを生成する（1ページ目の場合 `disabled`）
4. ページ番号ボタン（1〜totalPages）を生成する（現在ページは `is-active` クラスを付与）
5. `[次へ >]` ボタンを生成する（最終ページの場合 `disabled`）
6. totalPages が 1 以下の場合は `[< 前へ]` `[次へ >]` 両方を `disabled` にする

#### ページネーション表示ロジック

ダミーデータ25件・20件/ページのため最大2ページ。省略（`...`）表示は不要。全ページ番号を列挙する。

| 条件            | `[< 前へ]` | `[次へ >]` |
| --------------- | ---------- | ---------- |
| 1ページ目       | `disabled` | 有効       |
| 最終ページ      | 有効       | `disabled` |
| 1ページしかない | `disabled` | `disabled` |

#### キーワード検索対象カラム

| 棚ロケ（元）  | 棚ロケ（先）   | 商品コード | 商品名     | ロット番号 |
| ------------- | -------------- | ---------- | ---------- | ---------- |
| `srcLocation` | `destLocation` | `itemCode` | `itemName` | `lotNo`    |
