# [要件詳細] SCR-008: 出荷予定一覧

> 非機能要件・プロジェクト概要は [renew_REQUIREMENTS.md](renew_REQUIREMENTS.md) を参照すること。

---

## 機能概要

出荷予定情報を日付・キーワードでフィルタリングしながら一覧表示する画面。

---

## 機能詳細

### 機能1: 日付フィルタ・最終更新日時表示

- [ ] 日付を選択できる日付入力フォームを表示する（デフォルト値は翌日）
- [ ] 選択した日付に対応する出荷予定データをテーブルに表示する
- [ ] 最終更新日時をフォームの近くに表示する（モックアップのためダミー日時をハードコードで表示）

### 機能2: キーワード検索

- [ ] 日付フィルタの近くにキーワード入力フィールドを1つ配置する
- [ ] 入力値による部分一致で、テーブルの表示行をリアルタイムにフィルタリングする
- [ ] 検索対象カラム: 伝票No・商品コード・商品名・出荷先・ロット番号
- [ ] 検索は大文字・小文字を区別しない
- [ ] 入力フィールドをクリアすると全件表示に戻る

### 機能3: 出荷予定情報テーブル

- [ ] 出荷予定データをテーブル形式で表示する（モックアップのためダミーデータをハードコードで表示、8件）
- [ ] テーブルヘッダーはスクロール時も常に表示する（sticky）
- [ ] テーブルセクション見出し行の右端に **PDFダウンロードボタン**を配置する（クリックしても動作不要）
- [ ] テーブルのカラム:
  - `出荷予定日`
  - `出荷日時`
  - `伝票No`
  - `商品コード`
  - `商品名`
  - `棚ロケーション`
  - `出荷先`
  - `数量`（読み取り専用）
  - `単位区分`（読み取り専用）
  - `ロット番号`（読み取り専用）
  - `賞味期限`（読み取り専用）
  - `特記事項`（読み取り専用）

> カラム記載基準
>
> - `数量`: 1以上の数値
> - `単位区分`: パレット・ケース・ボール・ピースなど。未定義の場合は `‐` を表示
> - `ロット番号`: 任意の文字列
> - `賞味期限`: `yyyy/mm/dd` 形式。未定義の場合は `‐` を表示

### レイアウト構成

```text
┌──────────────────────────────────── viewport ────┐
│ [ヘッダー 固定]                                   │
├────────┬─────────────────────────────────────────┤
│ サイド  │ [対象日___] [🔍 検索___]                │← コントロール行（flex-shrink: 0）
│ バー    │ 最終更新: xx:xx:xx                      │
│        ├─────────────────────────────────────────┤
│        │ 出荷予定情報              ↑ 残り高さを占有 │
│        │  th1 │ th2 │ … ← sticky │ (内部scroll)  │
│        │  td  │ td  │ …          ↓               │
└────────┴─────────────────────────────────────────┘
```

ページ全体スクロールは発生させず、テーブル行が多い場合はテーブル内でスクロールする。実現方式は SCR-003 と同じ CSS Flexbox + `<body class="schedule-page">` スコープ方式を流用する。

---

### レイアウト実現方式（CSS Flexbox + ページ固有クラス）

`<body class="schedule-page">` にページ固有クラスを付与し、CSS セレクタでスコープを限定することで他画面への影響ゼロでページスクロールを抑制する。JS による高さ計算は使用しない。

| セレクタ                                | 設定値                                                    | 目的                                          |
| --------------------------------------- | --------------------------------------------------------- | --------------------------------------------- |
| `html, .schedule-page`                  | `height: 100%; overflow: hidden`                          | ページスクロール抑制                          |
| `.schedule-page .app-layout`            | `height: 100%`                                            | `.app-layout` の `min-height: 100vh` を上書き |
| `.schedule-page .app-body`              | `overflow: hidden`                                        | 縦方向伸張防止                                |
| `<main class="app-main schedule-main">` | `display: flex; flex-direction: column; overflow: hidden` | 縦 Flex コンテナ化                            |
| コントロール行                          | `flex-shrink: 0`                                          | 高さ固定                                      |
| `.schedule-table-wrapper`               | `flex: 1; overflow: auto; min-height: 0`                  | テーブル部分のみスクロール                    |
| `thead th`                              | `position: sticky; top: 0; z-index: 1`                    | ヘッダー固定                                  |
