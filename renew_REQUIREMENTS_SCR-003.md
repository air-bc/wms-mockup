## 1. 画面概要

取引先情報をCSVで一括登録し、登録済み取引先の一覧を管理する画面。  
取引先ごとの変換定義（CSVフィールドマッピング）の登録・編集もここから行う。

---

## 2. 画面構成

```text
┌─────────────────────────────────────────┐
│ 取引先マスタ                             │
├─────────────────────────────────────────┤
│ [CSVアップロードエリア]                  │
│   ドラッグ＆ドロップ または ファイル選択 │
│   [アップロードボタン]                   │
├─────────────────────────────────────────┤
```

## 3. 機能要件

### 3.1 CSVアップロード

| 項目     | 内容                                                                        |
| -------- | --------------------------------------------------------------------------- |
| 操作     | ファイル選択またはドラッグ＆ドロップでCSVを選択し、アップロードボタンで登録 |
| 確認画面 | なし（アップロード後、直接登録）                                            |
| 重複処理 | 既存の取引先と重複する場合は上書き更新する                                  |
| エラー時 | エラー内容（行番号・項目名）をインラインメッセージで表示する                |
| 成功時   | 「XX件登録しました」のトースト通知を表示し、一覧を再読み込みする            |

#### CSVフォーマット

| カラム         | 必須/任意 | 説明                 |
| -------------- | --------- | -------------------- |
| 会社名         | 必須      | 取引先の正式会社名   |
| 会社名（かな） | 必須      | ふりがな（全角かな） |
| 郵便番号       | 必須      | ハイフンなし7桁      |
| 住所           | 必須      | 都道府県から記載     |
| 電話番号       | 必須      | ハイフンあり         |
| 担当者名       | 任意      | 空欄可               |

---

### 3.2 取引先一覧

| 項目             | 内容                                            |
| ---------------- | ----------------------------------------------- |
| 表示形式         | テーブル（横スクロールあり）                    |
| ソート           | なし（登録順に表示）                            |
| ページネーション | データ件数が多い場合に表示（1ページあたり20件） |

#### テーブルカラム定義

| カラム名       | 必須/任意 | 説明                                                               |
| -------------- | --------- | ------------------------------------------------------------------ |
| 会社名         | 必須      |                                                                    |
| 会社名（かな） | 必須      |                                                                    |
| 郵便番号       | 必須      |                                                                    |
| 住所           | 必須      |                                                                    |
| 電話番号       | 必須      |                                                                    |
| 担当者名       | 任意      | 未登録の場合は空欄表示                                             |
| 変換定義       | -         | 定義あり：「あり ｜ 編集ボタン」、定義なし：「なし ｜ 登録ボタン」 |

---

### 3.3 検索

| 項目           | 内容                                                 |
| -------------- | ---------------------------------------------------- |
| 入力形式       | テキスト入力（1フィールド）                          |
| 対象カラム     | 会社名・会社名（かな）・担当者名を対象に部分一致検索 |
| 実行タイミング | Enterキーまたは検索ボタン押下で絞り込む              |

---

### 3.4 変換定義モーダル

取引先ごとの変換定義はCSVファイルで管理する。モーダルはそのCSVをアップロードするUIとして機能する。

| 項目         | 内容                                                                  |
| ------------ | --------------------------------------------------------------------- |
| 起動トリガー | 一覧の「登録」ボタン（未登録）または「編集」ボタン（登録済み）        |
| タイトル     | 対象取引先の会社名をモーダルタイトルに表示する                        |
| モーダル内容 | CSVファイルアップロードUI（SCR-002の変換定義CSVアップロードと同形式） |
| 確認画面     | なし（アップロード後、直接登録）                                      |
| 成功時       | モーダルを閉じ、一覧の変換定義列を「あり」に更新する                  |
| キャンセル   | 「キャンセル」ボタンまたはモーダル外クリックで閉じる（変更は破棄）    |
